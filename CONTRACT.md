# Build infrastructure contract

Build owner writes only tools/, packaging/, .github/workflows/, Makefile, .gitignore and this contract. No runtime or vendor edits; no remote writes or dispatches.

- Entry point: `make build` on macOS/Xcode defaults to real `arm64e` RootHide. `make check` is portable. `make smoke` compiles the actual core for iOS Simulator with `NG_TESTING=1` and links a parent-supplied harness.
- Parent supplies `Vendor/Theseus/Sources/Theseus/**/*.swift` (33), 1 Metal source, licenses/NOTICE; `Vendor/Glassify/Sources/Glassify/{Core,Platform,Shaders,...}` (4 C++ sources, all Platform/**/*.mm, original 51-file distribution); `Vendor/manifest.json` mapping every vendor relative path to original SHA256.
- Main compiles 33 vendor Swift files + `src/TheseusBridge.swift` + `src/TheseusBundle.swift`, all direct `src/*.m`/`src/*.mm` except any preference controller, 4 vendor C++, and all Platform/**/*.mm except GLSSwitch.mm. Preferences implementation lives in `prefs/*.m` or `prefs/*.mm`; prefs also compiles the shared `src/NGResources.m`. `src/NGPreferences.m` remains a main runtime source.
- Parent provides `src/Bridge.h`, `src/resource_bundle_accessor.h`, runtime sources, `src/Filter.plist`, `prefs/Resources/{Info,Root,entry}.plist`, prefs implementation, and approved icons in `assets/Icons/` or `prefs/Resources/` plus `assets/pkgicon.png`. `NGResources.m` exports `NGBundleResources()` and `NGBundleGlassify()`. Resource accessor defines `SWIFTPM_MODULE_BUNDLE=NGBundleGlassify()`. Constructor must be guarded with `NG_TESTING` to permit smoke compilation. Production leaves NG_TESTING undefined; simulator defines NG_TESTING=1.
- Main module is GlassSwitchDock. Compiler emits generated `GlassSwitchDock-Swift.h` into the object directory and adds that directory to ObjC include search. Swift bridging header is `src/Bridge.h`. Swift 5 / iOS 15.0 / ARC / blocks / O2 / GNU++17.
- Resources: `Library/Application Support/GlassSwitchDock/GlassSwitchDockResources.bundle/default.metallib` and nested `GlassifyShaders.bundle/default.metallib`. This is the only top-level runtime resources bundle.
- Preferences bundle: GlassSwitchDockPrefs.bundle executable GlassSwitchDockPrefs, exactly one PreferenceLoader entry; only keys `enabledSwitch`, `enabledDock`, `dockStyle` (0/1). Native link explicitly uses Preferences.framework; no dynamic lookup.
- If parent places a preference controller in src/, it must be identifiable as `*PrefsController*`, `*PreferencesController*`, or `*RootListController*`, subclass `PSListController`, or list it in `packaging/sources.json` `preference_sources`.
- Manifest accepted shapes: `{"files":{"Vendor/Theseus/...":"sha256",...}}`, same with digest objects `{ "sha256": "..." }`, a direct digest map, or `{"files":[{"path":"Vendor/...","sha256":"..."}]}`. Paths may alternatively start `Theseus/` or `Glassify/`. Metadata outside files is allowed. Every original vendor file is covered; .DS_Store and parent-generated UPSTREAM.json provenance are excluded unless explicitly listed. Vendor hashes are checked before build and before staging.
- Smoke harness: `tests/Harness/main.m` (or `.mm`), all `tests/Harness/*.m`, `*.mm`, and `*.swift`. `make smoke` produces signed `build/simulator/GlassSwitchDockHarness.app`, bundle id `com.minis.GlassSwitchDockHarness`, and copies both compiled libraries into the app resources. UIKit launch/runner lives in tests. `make smoke-core` builds/link-checks all actual core into a simulator dylib without requiring a harness. `tools/run-ci-simulator.sh` selects an available iPhone simulator and calls `tests/run-simulator.sh --app ... --device ... --output evidence/simulator-runtime`.
- Swift tests may use generated `FixtureConfig.h`: `NG_PREFERENCE_DOMAIN` is an NSString literal of `com.ning.glassswitchdock`. `NG_TESTING` is set in both Swift and Clang. Extra harness Swift is included only in make smoke.
- `make infra-check` runs 14 portable infrastructure checks; `make verify` re-extracts and native strict-sign verifies the requested dist deb (arm64e by default). No final deb is accepted solely from stage verification.
- CI is `.github/workflows/build.yml`, macos-26-intel, workflow_dispatch only. Input `simulator` defaults true. `tools/setup-macos.sh` selects installed Metal or downloads MetalToolchain and fetches a SHA256-pinned unmodified SDK16.5 Preferences link interface; it honors preexisting THEOS. Xcode SDK remains compile SDK. No repository creation, push, dispatch, signing identities or secrets are used by these scripts.

Build infrastructure status and exact source discovery will be recorded in tools output and ../evidence/build-infrastructure.json. Xcode builds and remote dispatch are left to parent.
